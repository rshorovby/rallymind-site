# Лендинг SwingSync

Статический сайт: **без сборки страниц, без npm-зависимостей, без бэкенда**. Открывается двойным кликом по `index.html`, деплоится копированием файлов.

Сборка есть только у ассетов — `tools/make-webp.sh` и `tools/make-fonts.sh`. Это разовые команды: страница работает на уже собранных файлах, и без Node, Python и этих скриптов сайт открывается и деплоится как есть.

Задача сайта — одно действие: открыть бота. Второе, вспомогательное — оставить заявку на iOS.

**Про название.** Продукт называется SwingSync. Раньше в проекте он назывался RallyMind, и это имя ещё живёт в технических местах, которые к сайту не относятся: папка `/Users/rust/rallymind-site`, репозиторий `rallymind-site`, набор иконок приложения `rallymind-icons` в ассетах iOS-клиента. На страницах сайта старого названия нет.

## Локальный просмотр

Лучше через сервер, а не `file://`: так поведение путей и шрифтов совпадает с продакшеном.

```bash
cd /Users/rust/rallymind-site
python3 -m http.server 8080
# открыть http://127.0.0.1:8080/
```

Через `file://` тоже работает — все пути относительные.

## Проверка и сборка ассетов

Всё в `tools/`, запускается из корня проекта. Скрипты не нужны для работы сайта — только для правок, поэтому и лежат отдельно.

| Команда | Что делает | Когда нужна |
|---|---|---|
| `tools/make-webp.sh` | PNG из `screens/` → WebP в `assets/img/` | после пересъёмки скриншотов |
| `tools/make-fonts.sh` | TTF из `fonts/` → woff2 в `assets/fonts/`, с сабсетом | после обновления шрифта из приложения |
| `tools/set-domain.sh URL` | подставляет домен в `og`, `canonical`, `hreflang`, JSON-LD; создаёт `robots.txt` и `sitemap.xml` | при публикации и при переезде на другой домен |
| `node tools/render-site.mjs` | перерисовывает `preview/` | перед ревью вёрстки |
| `node tools/render-site.mjs --audit` | проверяет переполнение по горизонтали, битые картинки и пропорции; код возврата 1 при провале | после любой правки вёрстки |

Аудит гоняет обе локали в обеих темах на 390 / 430 / 620 / 768 / 860 / 1280 px и проверяет четыре вещи: переполнение по горизонтали, битые картинки, совпадение пропорций в разметке с реальными размерами файлов и загрузку всех четырёх шрифтов. Последнее ловит самый тихий сбой: шрифт с неверным путём в `@font-face` не ломает вёрстку, а просто подменяется системным — это видно только на глаз. Требует поднятого локального сервера (порт 8080, как выше) и Node 22+; из зависимостей только локальный Chrome. В контейнере или песочнице, где вложенный sandbox Chrome не поднимается, запускать с `CHROME_NO_SANDBOX=1`.

Скрипты требуют `python3` с Pillow (`make-webp.sh`) и с fonttools + brotli (`make-fonts.sh`):

```bash
python3 -m pip install --user Pillow fonttools brotli
```

## Что заменить перед публикацией

Чеклист. Пункты 1–3 обязательны, остальное — по готовности.

1. **Цифры.** В `assets/site.js` заполнить `STATS`:
   ```js
   const STATS = { players: 128, analyses: 640, score: 3.8 };
   ```
   Незаполненные значения не показываются, а если пусто всё — секция целиком скрыта. Выдуманных чисел на сайте нет.
2. **Скриншоты.** Сняты и подключены: по три экрана на локаль.
   | Экран | RU | EN | Где на странице |
   |---|---|---|---|
   | Главная | `screen-home_ru` | `screen-home_en` | hero + секция «Экраны» |
   | Видео | `screen-video_ru` | `screen-video_en` | секция «Экраны» |
   | Разбор | `screen-result_ru` | `screen-result_en` | секция «Экраны» |

   Конвейер такой: **исходник PNG лежит в `screens/`, страница грузит WebP из `assets/img/`**. После пересъёмки положить PNG в `screens/` и выполнить `tools/make-webp.sh` — скрипт соберёт WebP (качество 85, альфа сохраняется) и покажет, сколько вышло. Это даёт ~90–135 КБ на файл вместо ~0,9–1,1 МБ; при 1179×2556 разница с PNG не видна даже при просмотре 1:1. Требования: пропорции **1179×2556** (iPhone 15 Pro), без рамки телефона — рамка уже есть в вёрстке. Пропорция задана в `site.css` в `.phone-screen` (`aspect-ratio: 1179 / 2556`): при съёмке в другом разрешении поправить её там же и в атрибутах `width`/`height` у `<img>`. Если добавляется локаль или экран — добавить `<img>` в `.phone-screen` в `index.html` и `en/index.html`.
3. **Политика конфиденциальности.** Создать `privacy.html` и раскомментировать ссылку в футере `index.html` (там помечено `ЗАМЕНИТЬ`). Для лендинга с подпиской и сбором данных это требование App Store и здравого смысла.
4. **Домен.** Публичный адрес — `https://advantace.app`. Инструмент — `tools/set-domain.sh <адрес>`: он подставляет адрес в `og:url`, `og:image`, `twitter:card`, `canonical`, `hreflang` и JSON-LD, снимает HTML-комментарий вокруг этого блока, если он снова появился, и переписывает `robots.txt` и `sitemap.xml`. После прогона скрипт проверяет, что парсер HTML эти теги видит. Повторный запуск заменяет прежний адрес и сохраняет путь `/en/`.
5. **OG-картинка.** Готово: `assets/img/og.png` (русская) и `assets/img/og-en.png` (английская), 1200×630. Собраны из шрифтов приложения (`fonts/`): фон-градиент `--court-2 → --court`, разметка корта, иконка приложения со скруглением, заголовок Inter SemiBold, глиняная плашка CTA. Пересобрать можно тем же составом; если меняется заголовок — поправить текст в картинке отдельно, она статичная.
6. **Проверить формулировки.** В FAQ про цену написано «продукт в открытой бете, разборы бесплатны» — это соответствует текущему состоянию (монетизация выключена). Когда тарифы появятся, текст нужно поменять.
7. **Проверить превью ссылки в Telegram.** Сайт будут расшаривать в чатах, а Telegram кеширует превью надолго — битое потом чинится долго. После `set-domain.sh` отправить ссылку себе в «Избранное» и посмотреть на карточку.

**Чего в разметке сознательно нет:** `FAQPage`. Он требует продублировать все шесть ответов в JSON-LD — два места для правки ради сниппета, который Google с 2023 года показывает только авторитетным сайтам. Вместо него размечен `SoftwareApplication` с названием, описанием и языками.

## Деплой

Целевой адрес — `https://advantace.app`, хостинг — Cloudflare Pages, проект `advantace`. Домен уже на неймсерверах Cloudflare. В репозиторий кладётся исходник; на Pages уходит каталог `dist/`.

Токен и id аккаунта лежат в `.env` (см. `.env.example`), файл в git не попадает. Права токена: Account → Cloudflare Pages → Edit, Account → Account Settings → Read, на зону `advantace.app` — Zone → Read и DNS → Edit.

```bash
cd /Users/rust/rallymind-site
tools/set-domain.sh https://advantace.app
tools/deploy.sh
```

`tools/deploy.sh` собирает `dist/` и вызывает `wrangler pages deploy`. Домен привязывается один раз после первой заливки запросом Pages API: `POST /accounts/{account_id}/pages/projects/advantace/domains` с телом `{"name":"advantace.app"}`, и так же для `www.advantace.app`. Редирект `www` на корень включается в настройках проекта. Зона `.app` отдаётся только по HTTPS.

**GitHub Pages.** Репозиторий `rshorovby/rallymind-site` по-прежнему публикует ветку `main` с корня, пока источник Pages не выключен. Это запасной адрес `https://rshorovby.github.io/rallymind-site/`. Вместе с ним в интернет попадают `screens/`, `fonts/` и `tools/` — Pages не умеет отдать только `dist/`. После того как `advantace.app` открывается, источник Pages в настройках репозитория стоит выключить.

**Про имя репозитория.** Он назван `rallymind-site` — по старому имени продукта, сознательно, чтобы не расходиться с папкой и историей проекта. На страницах старого названия нет. В адресе GitHub Pages сегмент `rallymind-site` виден, пока этот источник не выключен. На `advantace.app` его нет.

**Состояние на сейчас:** абсолютные адреса в страницах, `robots.txt` и `sitemap.xml` указывают на `https://advantace.app`. `canonical`, `og:image`, `hreflang` и JSON-LD стоят в разметке как настоящие теги. Пока DNS домена пустой, открывается прежний адрес GitHub Pages.

Порядок такой: сначала `set-domain.sh`, потом commit и push, затем `tools/deploy.sh`. Публичный адрес попадает в `og:url` и `canonical`, поэтому он должен быть проставлен до того, как ссылку увидит Telegram — превью кешируется надолго.

`git add -A` не потянет `preview/`, `dist/` и `.env` — они в `.gitignore`. Папки `screens/`, `fonts/` и `tools/` в репозитории намеренно: из них собираются WebP и woff2. В `dist/` они не копируются.

**Доступ к репозиторию.** Авторизация — через `gh` (`brew install gh`, затем `gh auth login`), он же настраивает credential helper для HTTPS. Вариант с SSH упирается в две вещи: в аккаунте не зарегистрирован ключ, а лежащий в `~/.ssh/rshorovby-GitHub` защищён парольной фразой, которой нет в ssh-agent. Плюс `~/.ssh/config` содержит путь с пробелом без кавычек (`IdentityFile /Users/rust/.ssh/shorov.rustam-GitLab Enterprise`), из-за чего ssh отбрасывает файл целиком и ломает все хосты сразу, а не только GitHub.

## CTA и аналитика переходов

Обе кнопки ведут в бота, различаясь кодом источника. Коды разные для языков, чтобы в кабинете было видно не только «пришёл с сайта», но и с какой версии:

| Кнопка | RU | EN |
|---|---|---|
| Открыть в Telegram | `?start=web` | `?start=web_en` |
| Следить за iOS | `?start=web_ios` | `?start=web_ios_en` |

Бэкенд для этого не нужен: бот уже сохраняет код из `/start` как `acquisition_source` при первом касании (`acquisition.py`, `bot.py`) и показывает его в кабинете тренера. То есть «сколько людей пришло с сайта» видно без единой строчки серверного кода.

Чтобы в кабинете вместо кода показывалась подпись, добавить в `rAI/acquisition.py`:

```python
SOURCE_LABELS = {
    "minsk_mir": "Минск-Мир",
    "web": "Сайт",
    "web_ios": "Сайт · iOS",
    "web_en": "Сайт · EN",
    "web_ios_en": "Сайт · iOS EN",
}
```

Новая метка — новый код в ссылке плюс строка в словаре.

## Дизайн-система

Палитра, радиусы, тени и тёмная тема берутся из `assets/tokens.css` — копии `rallyiOS/tokens.css`. Правило дизайн-системы соблюдается: `--clay` только для действия, `--ball` только для «готово/согласовано», `--court` — единственный тёмный акцентный фон.

Осознанные отличия лендинга от экранов приложения:

- **масштаб типографики крупнее** — у лендинга свой ритм, а не h1 в 22px;
- **заголовки набраны Inter 600, а не Space Grotesk** — в Space Grotesk нет кириллицы (правило из `lessons.md`), поэтому он оставлен только цифрам и метрикам;
- **шрифты подключены локально** через `@font-face` в `site.css`. Строку `@import` из Google Fonts в `tokens.css` пришлось удалить: иначе каждый посетитель ходил бы на сторонний CDN. При синхронизации файла с `rallyiOS/tokens.css` строку нужно удалять снова — в файле про это стоит комментарий.

### Шрифты

Страница грузит **woff2 из `assets/fonts/`, собранный из TTF в `fonts/`** (`tools/make-fonts.sh`). Конвейер такой же, как у скриншотов, и по той же причине: рядом лежащие исходник и готовый файл с похожими именами провоцируют правку не того файла.

Скрипт делает две вещи: конвертирует TTF в woff2 и вырезает лишние наборы. У Inter остаются латиница, латиница-1 (в ней `« » · × § ©`), кириллица и общая пунктуация (`— – « » “ ”`), у Space Grotesk — только цифры, разделители и тире. Итог: **1 353 КБ → 115 КБ**, при этом в начертаниях и в виде текста ничего не меняется. После сабсета скрипт проверяет, что контрольные символы на месте: молча вырезанная буква выглядит как подмена шрифта в одном слове.

Если шрифт обновляется из приложения — положить TTF в `fonts/` и выполнить `tools/make-fonts.sh`. Если правится список символов (например, появится третий язык), диапазоны заданы в начале скрипта.

### Иконки

В `assets/img/icons/` два набора, и оба работают одинаково: форма лежит в альфа-канале, цвет задаётся CSS-свойством `background-color` через `mask-image`. Поэтому иконки наследуют цвет темы и не «белеют» в тёмной.

- **13 альфа-масок** из родного набора приложения `rallymind-icons` — конвертация PNG;
- **6 SVG**, нарисованных под лендинг: `ai` (искра ИИ-разбора) и пять ударов. Родные иконки сегментов в мелком размере читались как заглушки — «Бэкхенд» и «Розыгрыш» были одной и той же двойной стрелкой, «У сетки» — сеткой из квадратов. Новые нарисованы в той же линии, что набор приложения (скруглённые концы, та же толщина). «Ноги» остались родной иконкой: она однозначна.

Чтобы добавить иконку приложения, взять PNG из `rallyiOS/Assets.xcassets/rallymind-icons/png/<name>.imageset/`, перевести в маску (форма уже лежит в альфа-канале, нужно только убрать цвет и уменьшить до 128px) и объявить класс `.icon-<name>` в `site.css`.

## Языки

Две отдельные HTML-страницы, а не подмена текста скриптом: без JS сайт остаётся читаемым, работают `hreflang` и поиск. Переключатель — обычные ссылки, состояние в localStorage не хранится.

Третий язык: скопировать `en/` в новую папку, перевести, добавить ссылку в `.lang-switch` и строку в блок `hreflang`.

## Доступность и мелочи

Сделано: skip-link, видимый `:focus-visible`, `aria-hidden` на декоративных SVG и иконках, `alt` у содержательных картинок, поддержка `prefers-reduced-motion` (анимации появления отключаются), семантические `header/main/section/footer`, `details/summary` для FAQ, контраст текста на тёмном фоне, `<html lang>`.

Скрипты: `site.js` не обязателен для контента — без JS страница читается, просто не будет цифр, появления секций и года в футере (там останется «2026»).

## Ограничения

- CI нет: сайт статический, собирать нечего.
- Аналитики на самом сайте нет (по lock #63 клиентская аналитика — отдельный срез). Считаются только переходы в бота.
- EN-версия написана, но вычитана только мной — стоит прочитать глазами носителя или хотя бы внимательно.
- Проверено `tools/render-site.mjs --audit`: переполнения по горизонтали нет на 390 / 430 / 620 / 768 / 860 / 1280 px, обе темы, обе языковые версии; все 8 картинок загружаются, пропорции в разметке совпадают с файлами. Живой Safari и iOS-симулятор не проверялись.
- Вес страницы: **~240 КБ до первого экрана** (hero 92 КБ + три шрифта из preload и Space Grotesk 115 КБ + CSS/JS 31 КБ) и **~465 КБ вся страница целиком** — остальное добирают два скриншота ниже сгиба по `loading="lazy"`. Было 2,8 МБ только на картинках плюс 1,35 МБ шрифтов.
- Inter-Medium (36 КБ) держится ради одного правила — `font-weight: 500` у плашек с ударами в секции «Что внутри». Если убрать его и перевести `.chip` на 600, станет легче ещё на 36 КБ, но плашки немного поменяют вид.

## Где лежит код

Итоговая папка — `/Users/rust/rallymind-site`. Копия внутри iOS-репозитория (`rallyiOS/site/`) — рабочая: песочница агента не даёт писать вне воркспейса без подтверждения на каждую операцию, поэтому сборка идёт там, а переносится одной командой. **При расхождении верна копия в `/Users/rust/rallymind-site`.** Папку `rallyiOS/site/` имеет смысл добавить в `.gitignore` iOS-репозитория или удалить после переноса.
